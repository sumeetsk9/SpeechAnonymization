# SpeechAnonymization
On a Swedish clinical corpus, architecture ORBIT-N+F → OpenVoice V2 achieves unlinkability at chance (πlink 0.071 = 1/N, min Cllr 0.799) with a formal zero-leakage guarantee on the timbre channel (I = 0 bits) and µ-GDP on vocal-tract scale — stronger unlinkability than neural baselines.
